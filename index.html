What it is

A preparation layer, not the live project.

Project Forge helps you define the target, close scope, separate stable rules from live project state, and assemble the files a ChatGPT Project needs to start cleanly.

It is not a notebook, a case archive, or a memory substitute. Its job is to prepare the project so the real work can start cleanly.

Core idea

Keep the core rules separate from the project package.

The system works because the rules and the live project state do not collapse into each other. The core defines how Forge works. The package carries what the real project needs at startup.
