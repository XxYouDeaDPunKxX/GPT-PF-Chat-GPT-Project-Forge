What it is

A preparation layer, not the live project.

Project Forge helps you define the target, close scope, separate stable rules from live case state, and assemble the opening materials a downstream ChatGPT Project will need.

It is not a notebook, a case archive, or a memory substitute. Its job is to prepare the project so the real work can start cleanly.

Core idea

Keep the governing core separate from the target-project package.

The system works because authority and live case state do not collapse into each other. The core defines how the preparation system works. The package carries what the downstream project needs at startup.

When it fits

Use it when a project should start from files, not carry-over.
